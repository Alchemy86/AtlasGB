# The bag, the PC, and the money — Pokémon Red/Blue

[← Pokémon Red/Blue](../README.md) · [by address](by-address.md) · [by name](by-name.md) · [the structures](structures.md) · [AtlasGB](../../../README.md)

Both item lists are the same shape: a count, then (item id, quantity) pairs, then an `$FF`
terminator. Three statements of one fact, which is why the harness checks all three agree — a
list whose count and terminator disagree is the signature of a half-finished write.

The bag holds twenty kinds of item; the PC's item store holds fifty. **`wBoxItems` is the PC
*item* store and has nothing to do with a Pokémon box** — the collision is the game's naming,
not ours, and it has misled readers of every map of this game.

Money and coins are both BCD, which is worth knowing before writing either: an ordinary binary
increment produces a value the game will happily display as nonsense digits.

### The first Poké Ball

The bag starts empty, so there is no ball to throw until one of two cartridge paths hands the
player one.

**A scripted gift of five.** Oak stops the player after the starter is chosen and explains that
watching a wild Pokémon is not enough — catching it is — then hands over five Poké Balls. The
gift is gated behind `EVENT_GOT_POKEBALLS_FROM_OAK`: `wEventFlags`+4 (`$D74B`), bit 4, the bit
immediately below `EVENT_GOT_POKEDEX` at bit 5 of the same byte. The script calls `GiveItem` with
`POKE_BALL, 5`, and the flag is set first, so retracing the scene a second time does not hand out
a second five.

**A purchase.** Every mart's stock and every item's price both come out of ROM tables, one entry
per item, ids 1-based. The prices at the point the game first lets the player buy anything:

| item | price |
|---|---:|
| POKÉ BALL | ¥200 |
| GREAT BALL | ¥600 |
| ULTRA BALL | ¥1200 |
| POTION | ¥300 |
| ANTIDOTE | ¥100 |

That table is `ItemPrices`, three-byte BCD per entry; the price of whatever item a transaction has
in hand is read into this atlas's own [`wItemPrices`](#s-wItemPrices) ($CF8F) while the mart menu
is open.

Viridian's — the first mart the player can reach, and the first mart list in the game — stocks
POKÉ BALL, ANTIDOTE, PARLYZ HEAL and BURN HEAL. **It is the only mart before Pewter's that carries
no POTION**, which is why three consecutive links of an item route have nothing to heal with but
the Pokémon Center: see
[No Potion is purchasable before Pewter](discoveries.md#no-potion-is-purchasable-before-pewter).

Only this early stock and price list is measured here; later marts are not covered by this page.
