[← Pokémon Red/Blue](../README.md) · [by address](by-address.md) · [by name](by-name.md) · [the structures](structures.md) · [AtlasGB](../../../README.md)

The same map indexed by `pret/pokered` symbol name, which is what you have when you are reading
a disassembly and want to know where something lives. Each row links to the entry's anchor on
its chapter page.

Aliases are listed separately, because a name you searched for should be findable whether or
not it is the one the atlas chose as canonical — `wPartyMons`, `wPartyMon1` and
`wPartyMon1Species` are all the same byte and all three appear here. Slots 2..N of a repeated
structure are folded onto slot 1; `atlas.tsv` is the exhaustive list.

Evidence badges: **R** the cartridge names it, **L** observed live, **I** an invariant covers
it, **·** no evidence yet. [What each one means.](../README.md#the-evidence)
