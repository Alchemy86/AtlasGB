# Sound

[← AtlasGB](../README.md) · [by address](by-address.md) · [by name](by-name.md) · [the structures](structures.md)

The sound engine is a little interpreter with eight software channels, and
`wChannelCommandPointers` is its program counter — one pointer per channel into a stream of
commands.

Everything in the game asks for a noise the same way: write an id to `wSoundID`. The rest of
this chapter is the interpreter's state — what each channel is playing, its duty cycle, its
vibrato, its pitch slide, its stereo panning.

This chapter is **not verified beyond the symbol file and the live sweep**. Nothing here has an
invariant, because none of it has a checkable relationship to anything else, and the audio work
in the emulator that verifies this atlas is about the console's sound hardware rather than about
this game's driver.
Treat the descriptions as what the names say.
