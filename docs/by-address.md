The whole map in address order, across every region. Each row links to its chapter, where the
full description lives, and each carries an anchor of its own — `by-address.md#a-D163` is a
permanent link to `$D163`.

**Slots 2..N of a repeated structure are folded away here.** 1,509 of the 2,898 rows are
`wBoxMon14Status` and its siblings; a list that included them would not be an index. Their
slot-1 row carries the count and the stride, and `atlas.tsv` beside this page remains the
exhaustive, greppable list — which is how anyone actually looks up a name like that.

Evidence badges: **R** the cartridge names it, **L** observed live, **I** an invariant covers
it, **·** no evidence yet. [What each one means.](../README.md#the-evidence)
